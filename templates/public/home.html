Frequently Asked Questions

Search portal policies, Semester 1 coursework rules, Coding Lab execution limits, and examination workflows.

Each role uses its dedicated portal (/admin-login/, /faculty-login/, /student-login/) backed by a unified Django authentication system. Access is verified strictly server-side from your RoleProfile so users only enter their authorized workspace.

Semester 1 features four verified core and elective subjects: 435C1A Discrete Mathematics, 435C1B Data Structures & Algorithms, 435E1A Data Engineering & Management, and 435C1C Python Programming. Semesters 2–4 are configurable by Campus Admin.

Submitted Python 3 code executes inside a server-side isolated process with strict timeout and restricted system-module protections, comparing standard output directly against problem test expectations.

Study notes cite uploaded subject PDFs and unit chapters directly while tracking live reading scroll progress inside the student Learning Materials workspace.

Examinations are scored automatically upon submission, and Skill DNA competencies advance only when backed by faculty-reviewed lab submissions, Python Coding Lab runs, or approved capstone project milestones.
